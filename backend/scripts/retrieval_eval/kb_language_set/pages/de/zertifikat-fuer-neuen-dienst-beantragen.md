# Zertifikat für einen neuen Dienst beantragen

## Wann

Ein neuer Dienst soll hinter dem Relay Proxy erreichbar sein und braucht ein eigenes Zertifikat.

## Antrag

1. Den Namen des Dienstes und die Webadresse festlegen.
2. Eine Zertifikatsanfrage erzeugen.
3. Die Anfrage an die Zertifizierungsstelle der Firma senden.
4. Das fertige Zertifikat im Ordner des Proxys ablegen.

## Laufzeit

Ein Zertifikat gilt 12 Monate. Der Antrag dauert meist zwei Arbeitstage, im Browser prüft man danach das Schloss-Symbol.

## Hinweis

Für Tests im Büro reicht ein internes Zertifikat. Für Kunden braucht man ein öffentliches.
