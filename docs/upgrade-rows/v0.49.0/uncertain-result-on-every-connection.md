## Note
An approved change on SSH, Kubernetes, a database or Vault whose answer was lost (a timeout or a dropped connection after MEHO sent it) now shows "uncertain" in every approvals view, like an HTTP change. A failed multi-step operation with such a step shows "uncertain" too, with the state of each step. The re-run route refuses these requests. Check the target first, then make a new request.

None.
