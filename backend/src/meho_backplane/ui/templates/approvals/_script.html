The block renders when the preview carries a ``script`` text or a ``script_unavailable`` reason, so it serves every operation whose preview uses these keys (``linux.script.run``). The text is shown as it is stored, autoescaped, in a ``
`` so line breaks and indents stay. Control and format
  characters (an escape code, a right-to-left override, a zero-width space)
  show as visible marks such as ``\u202e`` (``visible_marks``), as the CLI
  shows them. A script of more than one page (``script_pages``) shows "page N
  of M" and, while the request waits (``script_request_id`` is set),
  "previous page" and "next page" links that load the page into this block.
  After the decision there are no links: MEHO no longer keeps the script, and
  the block says that only page 1 is shown.
-#}
