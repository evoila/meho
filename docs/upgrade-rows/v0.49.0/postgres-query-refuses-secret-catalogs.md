## Note
`postgres.query` refuses, before it connects and for every login (also on a target with `extras.allow_superuser_query = true`), a statement that names one of these server catalogs, views or functions: stored role passwords (`pg_authid`, `pg_shadow`); replication connection strings (`pg_subscription`); foreign server logins (`pg_user_mapping`, `pg_user_mappings`, `_pg_user_mappings`, `user_mapping_options`); the SQL text of other sessions (`pg_stat_activity`, `pg_stat_get_activity`, `pg_stat_get_backend_activity`) and of past statements (`pg_stat_statements`, `pg_stat_statements_info`); server settings (`pg_settings`, `pg_file_settings`, `pg_show_all_settings`, `pg_show_all_file_settings`, `current_setting`); column statistics (`pg_statistic`, `pg_stats`, `pg_stats_ext`, `pg_stats_ext_exprs`, `pg_statistic_ext_data`); and the table-reading functions `table_to_xml`, `schema_to_xml`, `database_to_xml` and their variants. It also refuses `SHOW ALL` and a `SHOW` of `primary_conninfo`. `postgres.settings` puts the fixed mark `[REDACTED:param_name]` in place of a non-empty value of `primary_conninfo`, for every caller. Plain reads of other tables and the curated `postgres.*` operations run at once.

## Action
Use `postgres.activity` to see the sessions of a server, and `postgres.settings` to read settings. If a sensor runs `postgres.query` with one of these names or `SHOW` forms, it reads `unknown`: change its statement.
