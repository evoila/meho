# Set up the VPN client on a new laptop

## Before you start

You need the Orbit Gate client installer and the profile file for your user group. Ask the service desk for both.

## Install

1. Run the installer with admin rights.
2. Import the profile file into the client.
3. Sign in with your company account and confirm the second step on your phone.

## First connection

The first VPN connection can take up to a minute while the client loads its settings. A connection that never starts is a different problem: check the network cable or Wi-Fi first.

## Remove an old client

Remove the old client before you install a new one. Two clients on one laptop block each other.
