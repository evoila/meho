## Note
With `CUSTOM_POLICY` on, each step of a multi-step operation that a person approved as a whole asks the fixed rules. A step whose operation has only the plain "always ask" mark goes ahead under the approval of the whole run. A step that a fixed rule covers (a credential call, a change of rights or of the policy, a call to an address the caller gives, a destructive step, a delete) or that runs a command as root waits for its own approval, also when its policy would let it run at once and also when an Admin approved the run in the web console. On MEHO versions without this change, such a step with only the plain mark waits for its own approval. With the switch off, every step keeps its own approval when it is destructive, marked to always ask, "always wait" or a credential call. See https://github.com/evoila/meho/blob/main/docs/codebase/approvals.md.

## Action
None. `CUSTOM_POLICY` is off unless you turn it on. Before you turn it on, check which multi-step operations have steps with only the plain "always ask" mark: those steps will run under the approval of the whole run.
