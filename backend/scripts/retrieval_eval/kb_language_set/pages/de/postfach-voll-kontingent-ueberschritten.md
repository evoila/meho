# Postfach ist voll

## Symptom

Der Benutzer bekommt keine neue Post. Absender erhalten eine Unzustellbarkeitsnachricht mit dem Code MBX-552 und dem Text „quota exceeded“.

## Ursache

Das Postfach hat seine Größengrenze erreicht. Die Standardgrenze liegt bei 10 GB. Anhänge in den Ordnern „Gesendet“ und „Gelöschte Elemente“ sind die übliche Ursache.

## Lösung

1. „Gelöschte Elemente“ und den Ordner „Wiederherstellbare Elemente“ leeren.
2. Post, die älter als zwei Jahre ist, ins persönliche Archiv verschieben.
3. Braucht der Benutzer weiter mehr Platz, kann die Teamleitung eine Grenze von 20 GB beantragen.

## Kontrolle

In der Kontoansicht die Postfachgröße öffnen. Sie sollte unter 90 Prozent liegen. Eine Kollegin oder einen Kollegen bitten, eine Testnachricht zu senden.
