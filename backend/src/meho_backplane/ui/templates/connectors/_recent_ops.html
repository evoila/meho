Lists the last 10 ``operation_execution`` audit rows on this target, rendered on the server. Used both inside the detail page and as the response of ``GET /ui/connectors/{name}/recent-operations``. Refresh: ``recent-ops-refresh.js`` finds this card by its ``data-recent-ops-refresh`` attribute and, every 5 seconds while the page is visible, swaps in a fresh copy from ``recent_ops_url`` (``outerHTML``). There is no Broadcast subscription: Broadcast carries agent announcements only. The status line says when the rows were read; if a refresh fails, the script says so there and keeps the old rows. Every value renders through Jinja autoescaping. ``recent_ops_url`` is built on the server with the target name percent-encoded. Role: audit rows need the ``operator`` role (the audit API's minimum). With ``recent_ops_forbidden`` set the card shows a notice instead of rows and carries no refresh attributes, so the script does not poll. The fragment route returns this shape with HTTP 403.
