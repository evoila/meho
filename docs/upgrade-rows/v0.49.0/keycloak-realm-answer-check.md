## Note
Every Keycloak operation now reads the target's managed realm first and checks the realm name in Keycloak's answer. The name must be exactly the `managed_realm` of the target: the same letters, the same letter case and no space around it. MEHO refuses a Keycloak target whose `managed_realm` is not exactly the realm's name in Keycloak, also when only the letter case differs. The check runs before the call waits for approval, before `preview_operation` answers, and again when the call runs. A refused call stores no approval request and sends nothing more to Keycloak.

## Action
For each Keycloak target, compare its `managed_realm` (`meho targets describe <target> --json`) with the realm name that the Keycloak admin console shows. If they differ, also only in letter case, correct the realm name on the target. `meho targets update --extra` replaces the whole extras map, so give every extra the target has now: copy each key and value from the `extras` of `targets describe`, and change only `managed_realm`. For example, for a target with an `admin_realm`: `meho targets update <target> --extra admin_realm=<its value now> --extra managed_realm=<the name exactly as Keycloak shows it>`. Then run `meho targets describe <target> --json` again and check that every other extra is still there.
