## Note
A settings import with a token (the CLI, a script, an AI tool) that adds or changes a target now gets 403 and MEHO writes nothing from that file. A preview with a token still works, and a file with no target change still applies with a token. See https://evoila.github.io/meho/latest/guides/settings-file/#targets-are-changed-in-the-web-console.

## Action
Apply settings files that add or change targets in the web console. No schema action.
