# The setup page and the settings file

After the install, you set up your first tenant. A tenant is one
customer or team space in MEHO, with its own targets, policies and
users.

What exists today:

- **Add a tenant:** [Add a tenant](../guides/tenant-bootstrap.md) says
  how to make a tenant and its first targets.
- **The settings file:** [The settings file](../guides/settings-file.md)
  puts the policies, the conventions and the targets of a tenant into one
  file. You can export it, import it with a preview, and read the
  history. The file never holds a secret.

A graphical setup page is not part of the guide yet.
