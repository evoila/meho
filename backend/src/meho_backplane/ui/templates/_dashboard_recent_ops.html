The newest ``operation_execution`` audit rows of the tenant, read through the audit reader and rendered on the server. Used inside ``dashboard.html`` and as the response of ``GET /ui/dashboard/recent-operations``. Refresh: ``recent-ops-refresh.js`` finds the tray by its ``data-recent-ops-refresh`` attribute and, every 5 seconds while the page is visible, swaps in a fresh copy (``outerHTML``). The status line says when the rows were read; if a refresh fails, the script says so there and keeps the old rows. Every value renders through Jinja autoescaping. Context: recent_ops -- list of ``AuditEntry`` (newest first) recent_ops_url -- the refresh fragment path recent_ops_limit -- the row bound (50) recent_ops_updated_at -- ISO-8601 time the rows were read (UTC) -#} {% from "_icons.html" import icon %}
