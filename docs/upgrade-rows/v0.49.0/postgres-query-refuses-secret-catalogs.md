## Note
`postgres.query` refuses, before it connects and for every login (also on a target with `extras.allow_superuser_query = true`), a statement that names one of these server catalogs, views or functions: stored role passwords (`pg_authid`, `pg_shadow`); replication connection strings (`pg_subscription`); foreign server logins (`pg_user_mapping`, `pg_user_mappings`, `_pg_user_mappings`, `user_mapping_options`); the SQL text of other sessions (`pg_stat_activity`, `pg_stat_get_activity`, `pg_stat_get_backend_activity`) and of past statements (`pg_stat_statements`, `pg_stat_statements_info`); server settings (`pg_settings`, `pg_file_settings`, `pg_show_all_settings`, `pg_show_all_file_settings`, `current_setting`); column statistics (`pg_statistic`, `pg_stats`, `pg_stats_ext`, `pg_stats_ext_exprs`, `pg_statistic_ext_data`); the table-reading functions `table_to_xml`, `schema_to_xml`, `database_to_xml` and their variants; and the extension functions that read stored rows, `get_raw_page` of the pageinspect extension and `pg_get_wal_block_info` of the pg_walinspect extension. It also refuses `SHOW ALL`, a `SHOW` of `primary_conninfo`, and a statement in which a block comment holds the start of another block comment. `postgres.settings` reads a value of `primary_conninfo` with the rules of libpq, for every caller, and puts the fixed mark `[REDACTED:param_name]` in place of each secret value (the value of `password`, `sslpassword` and `oauth_client_secret`, and the password of an address); every other character stays. A value that libpq cannot read (also one with a parameter name that is not a libpq key word) makes `postgres.settings` refuse the call when it holds a secret name or an address password; then a sensor of `postgres.settings` that names `primary_conninfo` reads "unknown". A call without the names parameter is never refused. Plain reads of other tables and the curated `postgres.*` operations run at once.

## Action
Use `postgres.activity` to see the sessions of a server, and `postgres.settings` to read settings. If a sensor runs `postgres.query` with one of these names, `SHOW` forms or nested block comments, it reads `unknown`: change its statement.
