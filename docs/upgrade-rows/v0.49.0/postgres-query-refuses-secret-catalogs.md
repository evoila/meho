## Note
`postgres.query` refuses, before it connects and for every login (also on a target with `extras.allow_superuser_query = true`), a statement that names one of these server catalogs, views or functions: stored role passwords (`pg_authid`, `pg_shadow`); replication connection strings (`pg_subscription`); foreign server logins (`pg_user_mapping`, `pg_user_mappings`, `_pg_user_mappings`, `user_mapping_options`); foreign server options (`pg_foreign_server`, `foreign_server_options`, `_pg_foreign_servers`); the lines of `pg_hba.conf`, with the bind password of an ldap line (`pg_hba_file_rules`); the SQL text of other sessions (`pg_stat_activity`, `pg_stat_get_activity`, `pg_stat_get_backend_activity`) and of past statements (`pg_stat_statements`, `pg_stat_statements_info`); server settings (`pg_settings`, `pg_file_settings`, `pg_show_all_settings`, `pg_show_all_file_settings`, `current_setting`); column statistics (`pg_statistic`, `pg_stats`, `pg_stats_ext`, `pg_stats_ext_exprs`, `pg_statistic_ext_data`); the table-reading functions `table_to_xml`, `schema_to_xml`, `database_to_xml` and their variants; and the extension functions that read stored rows, `get_raw_page` of the pageinspect extension and `pg_get_wal_block_info` of the pg_walinspect extension; and `xpath_table` of the xml2 extension, which runs a SQL text built from its arguments. It also refuses `SHOW ALL`, a `SHOW` of `primary_conninfo`, and a statement in which a block comment holds the start of another block comment. `postgres.settings` shows a value of `primary_conninfo` whole or as one fixed mark that names the setting, never in part, for every caller. It shows the value whole only when it holds no at sign, percent sign, backslash or quote, none of the secret key words `password`, `sslpassword`, `oauth_client_secret`, `scram_client_key` and `scram_server_key` in any case, and no colon after the start word of an address; the call is not refused because of it. Plain reads of other tables and the curated `postgres.*` operations run at once.

## Action
Use `postgres.activity` to see the sessions of a server, and `postgres.settings` to read settings. If a sensor runs `postgres.query` with one of these names, `SHOW` forms or nested block comments, it reads `unknown`: change its statement.
