## Note
The web console has a Settings file page (/ui/settings). A person with tenant_admin or platform_admin uploads a settings file there, reads the preview of every change and every refused part with its reason, and applies it. A person there may also add or change targets, turn on `run_approval_target_kinds` and turn off `announce_gate_enabled`. The two policy changes need a reason, which MEHO keeps in the audit row; the other direction needs none. See https://evoila.github.io/meho/latest/guides/settings-file/#apply-a-file-in-the-web-console.
