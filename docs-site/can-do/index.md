# What MEHO can do

These pages tell you what MEHO does for you. They are for people who
want to know if MEHO fits, before they read how to run it.

Each page has the same four parts:

- **What it does** for you, in plain words.
- **Product versions** it covers.
- **State:** shipped (with the first version), beta, or planned.
- **Operator guide:** a link to the page with the steps and details.

## The pages

| Page | What you learn |
|---|---|
| [Ways to install MEHO](installation-options.md) | The ways to run MEHO, and which of them you can use today. |
| [Connectors overview](connectors-overview.md) | Which systems MEHO works with, and which versions. |
| [Approvals](approvals.md) | When MEHO waits until a second person approves a change. |
| [Secret values stay hidden](hidden-secrets.md) | How MEHO keeps passwords and keys out of answers, previews and traces. |

## What the states mean

| State | Meaning |
|---|---|
| **Shipped** | You can use it in a release. The page names the first version. |
| **Beta** | You can use it. Some gaps are known, and details may change. The [maturity index](../reference/maturity.md) lists each feature. |
| **Planned** | We decided to build it. It is not in a release. Do not plan a project on it without asking evoila. |

## Every claim gets a page

When evoila tells a customer that MEHO can do something, that claim has
a page in this section. The page says what it does, which versions it
covers, its state and where the operator guide is. The list of claims
links to these pages. A new claim is not final until its page exists.
