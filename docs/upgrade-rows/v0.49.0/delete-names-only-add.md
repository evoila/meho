## Note
With the switch `CUSTOM_POLICY` on, the setting `SERVICE_GRANT_DELETE_SHAPED_PATTERNS` only adds names to the built-in delete names. An install whose setting replaced the built-in names gets them back, so more calls wait for a person: a standing grant no longer covers an operation with a built-in delete name. With the switch off, nothing changes.

## Action
None. If you turn on `CUSTOM_POLICY`, keep only your own extra delete names in `SERVICE_GRANT_DELETE_SHAPED_PATTERNS`.
