## Note
A runner can now log in with a key pair it makes at its own site, and renews its own short token. `meho runner-principal register` prints a one-time enrollment code. The change adds a database migration and the route `/api/v1/runner-principals/enroll`. A runner with the fixed `MEHO_RUNNER_TOKEN` works as before. Register is for people: a service login or an agent login gets 403 `human_principal_required`. Revoke works the same for every runner, with a key or with a fixed token: it turns the runner's Keycloak client off and deletes it, with its public key and its Keycloak secret. The runner row stays, marked revoked, and its enrollment code is cleared; `meho runner-principal list` shows it only with revoked runners included, and `show` shows it as revoked. The name stays taken, so a new register of it gets 409. A revoked runner cannot be brought back; a new runner needs a new name and a new enrollment code. A token the runner already has works until it ends.

## Action
Nothing is needed to upgrade. To use the key login, start the runner with `MEHO_RUNNER_ENROLLMENT_CODE` set to the code from `meho runner-principal register`, and keep `MEHO_RUNNER_KEY_DIR` on a volume that stays. See https://evoila.github.io/meho/latest/guides/satellite-gateway/ for the steps.
