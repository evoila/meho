## Note
Every Keycloak operation now reads the target's managed realm first and checks the realm name in Keycloak's answer. The name must be exactly the `managed_realm` of the target: the same letters, the same letter case and no space around it. MEHO refuses a Keycloak target whose `managed_realm` is not exactly the realm's name in Keycloak, also when only the letter case differs. The check runs before the call waits for approval, before `preview_operation` answers, and again when the call runs. A refused call stores no approval request and sends nothing more to Keycloak.

## Action
For each Keycloak target, compare its `managed_realm` (`meho targets describe <target>`) with the realm name that the Keycloak admin console shows. If they differ, also only in letter case, correct the realm name on the target with a targets file, so every other extra keeps its value and its type (a list, a map, `true` or `false`, a number). When you still have the targets file you imported the target from, use it: change only the value of `managed_realm` there, to the name exactly as Keycloak shows it. Without that file, read the target as MEHO stores it from the REST API: `TOKEN=$(meho login --print-token https://<meho-host>)`, then `curl -H "Authorization: Bearer $TOKEN" https://<meho-host>/api/v1/targets/<target>`. Write a file `fix-realm.yaml` with one entry under `targets:` that gives the `name`, `product` and `host` of that answer, and under `extras:` the whole `extras` object of that answer, pasted as it is (JSON is also YAML), with only the value of `managed_realm` changed. Do not copy the extras from `meho targets describe --json`: it can round a large number. Run `meho targets import fix-realm.yaml --update --dry-run` and check that the plan updates only this target, then run `meho targets import fix-realm.yaml --update`. Read the target again with the same `curl` command and check that every other extra still has the same value. Do not use `meho targets update --extra` for this: it replaces the whole extras map and stores every value as text.
